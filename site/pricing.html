Questions people actually ask

Is the data really free, or is this a trial?
Really free. OpenStreetMap basemaps, Mapterhorn terrain, NASA GIBS satellite and weather, Kontur population and Natural Earth borders are all public or openly licensed and need no key. The engine is built so it cannot quietly start calling a metered service — every network read goes through one registry with rate limits, and the render loop reads only from local disk.
What hardware do I need?
A machine with a GPU and ffmpeg. It was developed on a Radeon RX 6600 XT, where it renders around 9 frames a second at 720p and uses the hardware h264 encoder. It runs without a GPU too, on software rendering, but expect several times longer.
Can I sell the videos I make?
Yes. The licence covers the software; the output is yours. The data licences do carry through, which is why attribution is burned into every frame automatically rather than left to you to remember. If you use the bundled music, keep the composer credit in your description.
Do I need to write code?
No. The dashboard has a map region picker, place search, overlay checkboxes and a narration box. A JSON job file and a CLI are there when you want repeatability, but nothing requires them.
What does the hosted queue in Studio do?
It splits the system: a small dashboard runs on a cheap host and holds the job queue, while your own machine polls it, renders locally and uploads the finished file. Nothing heavy runs on the host, so it stays inside a free tier — you get a shareable URL without paying for render compute.
Is there a refund?
Fourteen days, no questions. Render something first — if it does not do what you needed, ask and it is returned.
